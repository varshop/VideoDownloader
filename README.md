# محمّل الفيديو (Android)

تطبيق أندرويد: الصق الرابط (أو شاركه من أي تطبيق عبر زر "مشاركة") ← اختر الصيغة والجودة ← تحميل.

- **المواقع:** يوتيوب، تيك توك، إنستغرام، فيسبوك، X/تويتر، ريديت، بنترست، فيميو، سناب شات، وآلاف المواقع الأخرى (عبر yt-dlp).
- **الصيغ:** MP4 / MKV / WEBM (فيديو) — MP3 / M4A / WAV (صوت) — جودة من 360p حتى الأعلى.
- **الحفظ:** مجلد `التنزيلات/VideoDownloader` (بدون صلاحيات تخزين).
- **المتطلبات:** أندرويد 10 فما فوق.

## بناء APK عبر GitHub (بدون تثبيت أي شيء)
1. أنشئ مستودعاً جديداً على GitHub وارفع كل محتويات هذا المجلد.
2. افتح تبويب **Actions** ← سيبدأ **Build APK** تلقائياً (أو اضغط Run workflow).
3. بعد دقائق افتح التشغيل المكتمل ← **Artifacts** ← حمّل `VideoDownloader-APK` وفك الضغط ← ثبّت `app-release.apk`.

## البناء محلياً
افتح المجلد في Android Studio ثم Build ‹ Build APK(s).

## ملاحظات
- المواقع تغيّر أنظمتها كثيراً؛ إذا فشل موقع اضغط "تحديث المحرك" داخل التطبيق.
- حمّل فقط المحتوى الذي تملكه أو يُسمح لك بتحميله، والتزم بشروط كل منصة وحقوق النشر.
