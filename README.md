# Videodownloader

تطبيق أندرويد لتحميل الفيديوهات من أي موقع: الصق رابطاً أو عدة روابط ← اختر الصيغة ← حمّل.

## المميزات
- إضافة عدة روابط معاً (زر + ، أو لصق قائمة روابط، أو مشاركة من أي تطبيق).
- لكل رابط: صورة مصغّرة وعنوان ومدة، واختيار صيغته وجودته بشكل مستقل، أو "تحميل الكل" دفعة واحدة.
- اكتشاف كل الصيغ المتاحة للفيديو (جودات، صوت فقط، بدون صوت) وتحميل أي صيغة منها.
- مواقع غير مدعومة؟ يفحص التطبيق كود الصفحة ويستخرج روابط الفيديو الموجودة فيها.
- تحميل سريع (8 اتصالات متوازية) و3 تحميلات بالتوازي.
- استكمال التحميل بعد الإيقاف أو الانقطاع أو إعادة تشغيل التطبيق.
- يعمل في الخلفية (خدمة أمامية) مع إشعارات: جاري التحميل، تم، فشل (مع زر إعادة المحاولة)، في انتظار الشبكة.
- الصيغ: MP4 / MKV / WEBM / MP3 / M4A / WAV.
- يُحفظ في: التنزيلات / Videodownloader (أندرويد 10 فما فوق).

## بناء APK عبر GitHub
1. أنشئ مستودعاً جديداً فارغاً.
2. افتح المجلد بعد فك الضغط، حدّد **كل ما بداخله** (بما فيه المجلد `.github`) واسحبه إلى صفحة
   **Add file ‹ Upload files** ثم Commit.
3. تبويب **Actions** ‹ Build APK. خطوة "Check project structure" تخبرك بأي ملف ناقص.
4. بعد النجاح: افتح التشغيل ‹ **Artifacts** ‹ `Videodownloader-APK` ‹ ثبّت `app-release.apk`.

> حمّل فقط المحتوى الذي تملكه أو يُسمح لك بتحميله، والتزم بشروط كل منصة.
